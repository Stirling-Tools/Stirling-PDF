Method

  • One node at __CORES__ vCPU. CPU and memory read from the container cgroup; CPU is core-seconds per request (median of 3). Max req/s measured directly at concurrency __CORES__.
  • Peak MB is the container high-water mark including page cache, so it overstates process memory for I/O-heavy tools — treat as an upper bound.
  • Each endpoint used one representative input with schema-default parameters, so cost scales with document size and settings. Full data: endpoint_benchmark.csv.
