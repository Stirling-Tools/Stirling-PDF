WHAT THIS COVERS
================

Lucide icon geometry used in this project. Two places rely on this notice:

1. The lucide icons src/core/icons/icons.ts maps. Their geometry is read from
   the lucide-static package at build time and is not checked in; it disappears
   if that package is removed.

2. Two icons in src/core/icons/svg/stirling/ that reuse lucide geometry so they
   sit in the same visual family. These are checked in and do NOT disappear
   with the package:

     users-plus.svg  the person body   M16 21v-2a4 4 0 0 0-4-4H6a4 4 0 0 0-4 4v2
                     the second head   M16 3.128a4 4 0 0 1 0 7.744
                     (from lucide "users"; head circle and plus are ours)

     file-pdf.svg    the page outline  M6 22a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h8
                                       a2.4 2.4 0 0 1 1.704.706l3.588 3.588
                                       A2.4 2.4 0 0 1 20 8v12a2 2 0 0 1-2 2z
                     the corner fold   M14 2v5a1 1 0 0 0 1 1h5
                     (from lucide "file"; the PDF letterforms are ours)

Neither source icon appears in the Feather-derived list below, so only the ISC
terms apply to them. Keep this file for as long as either of those svgs, or the
icons.ts maps, remains. task frontend:lint:icons fails if it goes missing.
